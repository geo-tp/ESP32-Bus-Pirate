Use these recipes when

Practical entry points for learning the firmware feature by feature, while keeping the full Wiki as the reference.

  • Start from zeroOpen Web Serial, select a mode, read help, check status and learn the CLI without a long setup.
  • Find unknown hardwareScan I2C, read UART logs, detect GPIO activity, identify chips and avoid guessing before writing code.
  • Backup memoriesDump SPI flash, I2C EEPROM, 1-Wire EEPROM or smartcard data before repair work or firmware experiments.
  • Use ESP32 adaptersRun ESP32 serprog, ESP32 SUMP logic analyzer, USB CDC, IR Toy/LIRC and browser-based SPI flash workflows.
  • Practice real protocolsLearn UART, I2C, SPI, DIO, Infrared, SubGHz, RFID, CAN, Ethernet, BLE and USB through small tasks.
  • Build repeatable testsUse alias, repeat, command chaining, delays, profiles and Python automation for daily bench workflows.
  • TroubleshootIdentify and resolve issues in your hardware setup or firmware configuration.
  • Learn by practiceUse the recipes to learn the firmware feature by feature, while keeping the full Wiki as the reference.
